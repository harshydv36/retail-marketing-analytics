# 🛒 Retail & Marketing Analytics Pipeline

An end-to-end retail and marketing analytics pipeline built with Python to analyze **customer retention**, **sales performance**, and **marketing efficiency** across multiple regions and product categories.

---

## 📌 Project Overview

This project uses the **Online Retail II dataset (UCI/Kaggle)** — containing 1M+ transactions from a UK-based online retailer (2009–2011) — to build a comprehensive analytics pipeline that delivers actionable business insights.

---

## 🚀 Key Features

- **RFM Analysis & Customer Segmentation** — Identifies high-value customer groups using Recency, Frequency, and Monetary scoring with K-Means clustering
- **Customer Lifetime Value (CLV)** — Calculates and predicts long-term customer value to guide retention strategies
- **Customer Acquisition Cost (CAC)** — Estimates marketing spend efficiency per acquired customer
- **Sales Performance Analysis** — Breaks down revenue trends by region and product category to support inventory and resource decisions
- **Visualizations & Dashboards** — Clear, stakeholder-ready charts communicating customer behavior, campaign performance, and revenue insights

## 📊 Dataset

**Online Retail II — UCI Machine Learning Repository**

- 📥 Download: (https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)
- 🗂️ 1,067,371 transactions | 8 columns
- 🌍 Customers from 40+ countries
- 📅 Dec 2009 – Dec 2011


## 📈 Results & Insights

- Segmented customers into **4 distinct RFM clusters** (Champions, Loyal, At-Risk, Lost)
- Identified top **20% of customers driving 60%+ of revenue**
- Calculated CLV per segment to prioritize **high-value retention efforts**
- Uncovered regional sales inconsistencies to improve **inventory allocation**
